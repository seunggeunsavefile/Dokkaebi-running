# 도깨비 캡쳐: 애매먕량 대질주

- 동명의 웹툰 ‘도깨비 캡쳐’를 기반으로 한국의 도깨비 설화들을 재해석하여 2D 러닝 액션 게임을 녹여냈다.한 손으로 가능한 간단한 조작과 대중에게 친숙한 도깨비라는 설정을 이용해 남녀노소에게 플레이 가능하게 제공하였습니다
